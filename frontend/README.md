# CampusCare AI - Frontend Architecture

The frontend is served directly through Flask templates and static assets for zero-build overhead and rapid 24-hour hackathon iteration:
- `templates/index.html`: Responsive single-page interface with dynamic role switching (Student, Service Provider, Admin).
- `static/css/style.css`: Modern glassmorphic and high-contrast UI design system.
- `static/js/app.js`: Vanilla JavaScript state management, real-time AI classification preview, and REST API communication.
